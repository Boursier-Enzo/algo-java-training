# Exercice 13 - Pattern Recognition

## Objectif

Identifier des structures de code récurrentes (patterns) et comprendre leur comportement.

## Concept clé

**Les mêmes patterns reviennent partout : accumulateur, recherche, transformation, filtrage...**

Reconnaître un pattern permet de comprendre instantanément ce que fait le code.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en identifiant le pattern de chaque fonction
3. **Exécute le programme** pour vérifier
4. **Nomme chaque pattern** reconnu

## Ce qui est noté

Ta capacité à **identifier le pattern** et prédire le résultat sans tracer chaque ligne.

## Règle d'or

**Reconnais la structure, pas les détails. Le pattern te dit ce que fait le code.**
