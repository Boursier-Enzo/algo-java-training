# Exercice 03 - Conditions Imbriquées

## Objectif

Tracer le chemin d'exécution à travers des conditions `if/else` imbriquées.

## Concept clé

**La machine ne lit pas TOUTES les branches. Elle n'exécute QUE le chemin où la condition est vraie.**

Quand une condition est fausse, tout le bloc est ignoré. Ne trace que ce qui est réellement exécuté.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en indiquant quel chemin est pris à chaque condition
3. **Exécute le programme** pour vérifier
4. **Corrige ton traçage** si nécessaire

## Ce qui est noté

Ta capacité à identifier **le bon chemin d'exécution** parmi toutes les branches possibles.

## Règle d'or

**Pour chaque `if`, évalue la condition et trace UNIQUEMENT la branche exécutée.**
