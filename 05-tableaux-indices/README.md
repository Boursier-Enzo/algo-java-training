# Exercice 05 - Tableaux et Indices

## Objectif

Tracer l'accès et la modification d'éléments dans un tableau via leurs indices.

## Concept clé

**Un tableau commence à l'indice 0. `tab[2]` est le TROISIÈME élément, pas le deuxième.**

La machine accède à l'adresse mémoire exacte. Elle ne "comprend" pas ce que représente le tableau.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en traçant chaque accès/modification du tableau
3. **Exécute le programme** pour vérifier
4. **Corrige ton traçage** si nécessaire

## Ce qui est noté

Ta capacité à **suivre les indices** et l'état du tableau après chaque modification.

## Règle d'or

**Dessine le tableau avec ses indices. Mets à jour visuellement à chaque modification.**
