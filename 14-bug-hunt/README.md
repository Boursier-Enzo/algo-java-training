# Exercice 14 - Bug Hunt

## Objectif

Trouver les bugs dans le code par lecture seule, sans exécuter.

## Concept clé

**Un bon développeur trouve les bugs en lisant le code, pas en spammant des console.log.**

Trace mentalement. Le bug apparaîtra.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en identifiant les bugs de chaque fonction
3. **Exécute le programme** pour vérifier tes trouvailles
4. **Propose une correction** pour chaque bug

## Ce qui est noté

Ta capacité à **trouver les bugs par lecture** et à **expliquer pourquoi** c'est un bug.

## Règle d'or

**Trace le code avec des valeurs limites : 0, 1, tableau vide, premier élément, dernier élément.**
