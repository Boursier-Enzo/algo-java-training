# Exercice 07 - Effets de Bord

## Objectif

Comprendre la différence entre modifier une variable et retourner une valeur.

## Concept clé

**Un type primitif (int, boolean...) est COPIÉ quand il est passé en paramètre. Modifier la copie ne change pas l'original.**

Par contre, un tableau ou objet passé en paramètre peut être modifié directement.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en traçant ce qui est modifié ou non
3. **Exécute le programme** pour vérifier
4. **Corrige ton traçage** si nécessaire

## Ce qui est noté

Ta capacité à distinguer **ce qui est modifié** de **ce qui ne l'est pas**.

## Règle d'or

**Demande-toi toujours : est-ce que je modifie l'original ou une copie ?**
