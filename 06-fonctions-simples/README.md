# Exercice 06 - Fonctions Simples

## Objectif

Tracer les appels de fonctions : passage de paramètres, exécution, et valeur de retour.

## Concept clé

**Quand une fonction est appelée, la machine "saute" dedans, exécute, puis revient avec le résultat.**

Les paramètres sont des COPIES des valeurs passées (pour les types primitifs).

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en traçant chaque appel de fonction
3. **Exécute le programme** pour vérifier
4. **Corrige ton traçage** si nécessaire

## Ce qui est noté

Ta capacité à **suivre le flux d'exécution** entre le main et les fonctions appelées.

## Règle d'or

**Pour chaque appel : note les paramètres reçus, trace l'exécution interne, note la valeur retournée.**
