# Exercice 11 - Reverse Engineering

## Objectif

Déduire ce que fait un code en analysant sa structure, sans se fier aux noms.

## Concept clé

**Les noms de variables et fonctions peuvent mentir. Seul le code dit la vérité.**

Ignore les noms. Trace le code. Déduis ce qu'il fait vraiment.

## Consignes

1. **Lis le code** dans `src/Main.java` (les noms sont volontairement cryptiques)
2. **Remplis `PREDICTION.md`** en déduisant ce que fait chaque fonction
3. **Exécute le programme** pour vérifier
4. **Corrige ton analyse** si nécessaire

## Ce qui est noté

Ta capacité à **comprendre le comportement réel** du code, pas ce que les noms suggèrent.

## Règle d'or

**Cache les noms. Lis le code. Décris ce qu'il fait.**
