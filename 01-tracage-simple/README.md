# Exercice 01 - Traçage Simple

## Objectif

Tracer l'exécution d'un programme ligne par ligne, en suivant l'évolution des variables.

## Concept clé

**La machine ne devine rien. Elle exécute ligne par ligne, instruction par instruction.**

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en détaillant l'évolution des variables ligne par ligne
3. **Exécute le programme** pour vérifier ta prédiction
4. **Corrige ton traçage** si tu t'es trompé

## Ce qui est noté

**Pas la prédiction de la sortie** (il suffirait d'exécuter pour l'avoir), mais **ton traçage ligne par ligne** : l'évolution des variables à chaque instruction.

## Règle d'or

**Ne lance PAS le code avant d'avoir tracé dans `PREDICTION.md`.**
