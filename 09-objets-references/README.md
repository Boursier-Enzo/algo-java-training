# Exercice 09 - Objets et Références

## Objectif

Comprendre que plusieurs variables peuvent pointer vers le même objet en mémoire.

## Concept clé

**Quand tu fais `obj2 = obj1`, tu ne copies pas l'objet. Tu copies la RÉFÉRENCE (l'adresse mémoire).**

Les deux variables pointent vers le même objet. Modifier l'un modifie l'autre.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en traçant quelles variables pointent vers quoi
3. **Exécute le programme** pour vérifier
4. **Corrige ton traçage** si nécessaire

## Ce qui est noté

Ta capacité à identifier **quand deux variables partagent le même objet**.

## Règle d'or

**Dessine les boîtes (objets) et les flèches (références). Deux flèches vers la même boîte = même objet.**
