# Exercice 18 - Architecture Complexe

## Objectif

Tracer l'exécution d'un programme avec plusieurs classes qui interagissent.

## Concept clé

**Dans un vrai projet, le code est réparti sur plusieurs classes. Il faut suivre les appels entre classes.**

Chaque classe a sa responsabilité. Comprends qui fait quoi.

## Consignes

1. **Lis tous les fichiers** dans `src/`
2. **Remplis `PREDICTION.md`** en traçant les interactions entre classes
3. **Exécute le programme** pour vérifier
4. **Corrige ton traçage** si nécessaire

## Ce qui est noté

Ta capacité à **suivre le flux entre plusieurs classes** et comprendre leurs interactions.

## Règle d'or

**Identifie d'abord QUI appelle QUI, puis trace les données.**
