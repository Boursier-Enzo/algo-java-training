# Exercice 19 - Code Legacy

## Objectif

S'intégrer dans du code existant mal documenté et ajouter une fonctionnalité.

## Concept clé

**En entreprise, tu travailles rarement sur du code neuf. Tu dois comprendre l'existant avant de modifier.**

Lis, comprends, puis modifie.

## Consignes

1. **Lis le code** dans `src/` (code existant sans commentaires)
2. **Remplis `PREDICTION.md`** en documentant ce que fait chaque classe/méthode
3. **Ajoute la fonctionnalité demandée** (décrite dans PREDICTION.md)
4. **Exécute le programme** pour vérifier

## Ce qui est noté

Ta capacité à **comprendre du code existant** et à **t'y intégrer proprement**.

## Règle d'or

**Ne casse pas l'existant. Comprends avant de modifier.**
