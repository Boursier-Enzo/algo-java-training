# Exercice 17 - Optimisation

## Objectif

Identifier et corriger les inefficacités dans le code.

## Concept clé

**Un code peut être correct mais inefficace. Comprendre ce qu'il fait permet de l'optimiser.**

Cherche les calculs inutiles, les boucles évitables, les parcours redondants.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en identifiant le problème de chaque fonction
3. **Propose une version optimisée** de chaque fonction
4. **Compare** avec la correction

## Ce qui est noté

Ta capacité à **identifier les inefficacités** et proposer une meilleure solution.

## Règle d'or

**Compte les opérations. Moins = mieux.**
