# Exercice 16 - Refactoring Mental

## Objectif

Simplifier du code sans changer son comportement.

## Concept clé

**Un bon code fait la même chose avec moins de lignes et plus de clarté.**

Comprendre le code permet de le simplifier.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** avec une version simplifiée de chaque fonction
3. **Vérifie** que ta version simplifiée produit le même résultat

## Ce qui est noté

Ta capacité à **comprendre puis simplifier** sans casser le comportement.

## Règle d'or

**Même entrée = même sortie. Toujours.**
