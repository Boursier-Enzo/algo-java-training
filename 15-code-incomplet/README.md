# Exercice 15 - Code Incomplet

## Objectif

Compléter du code à trous en comprenant ce que chaque partie doit faire.

## Concept clé

**Pour compléter du code, tu dois comprendre le contexte : ce qui vient avant, ce qui vient après.**

Analyse la structure existante pour déduire ce qui manque.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** avec les valeurs à mettre dans les trous `???`
3. **Remplace les `???`** dans le code et exécute pour vérifier
4. **Corrige** si le résultat n'est pas celui attendu

## Ce qui est noté

Ta capacité à **déduire le code manquant** à partir du contexte.

## Règle d'or

**Lis ce qui entoure le trou. La réponse est dans le contexte.**
