# Exercice 12 - Code Mystère

## Objectif

Comprendre un algorithme complexe en le traçant pas à pas.

## Concept clé

**Quand le code semble incompréhensible, trace-le avec des valeurs concrètes.**

Ne cherche pas à "comprendre" d'abord. Exécute d'abord, comprends ensuite.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en traçant avec les valeurs données
3. **Exécute le programme** pour vérifier
4. **Déduis ce que fait l'algorithme** après avoir tracé

## Ce qui est noté

Ta capacité à **tracer un algorithme inconnu** et à **déduire son comportement**.

## Règle d'or

**Trace d'abord, comprends ensuite. Pas l'inverse.**
