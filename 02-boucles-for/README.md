# Exercice 02 - Boucles For

## Objectif

Tracer l'exécution d'une boucle `for` en suivant l'évolution de la variable de boucle et des variables internes.

## Concept clé

**Une boucle for répète des instructions. La machine exécute CHAQUE itération, une par une.**

Ne saute pas d'itérations dans ta tête. Trace TOUTES les itérations.

## Consignes

1. **Lis le code** dans `src/Main.java`
2. **Remplis `PREDICTION.md`** en détaillant chaque itération de la boucle
3. **Exécute le programme** pour vérifier
4. **Corrige ton traçage** si nécessaire

## Ce qui est noté

Ta capacité à tracer **chaque itération de la boucle** avec l'état des variables à chaque tour.

## Règle d'or

**Trace TOUTES les itérations, même si ça semble répétitif.**
